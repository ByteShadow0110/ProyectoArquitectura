# 04 · UX / Maqueta (T3)

Abrir `prototype/index.html`. El selector **«Ver como»** de la barra superior cambia el rol (Admin / Supervisor / Operativo) y muestra/oculta menú y botones según la matriz de permisos.

## Mapa de navegación
```
login ─▶ dashboard ─┬─▶ personas ─▶ persona-detalle ─▶ persona-form
                    ├─▶ activos ──▶ activo-detalle ──▶ activo-form (+ asignar)
                    ├─▶ solicitudes (aprobar / rechazar)
                    ├─▶ reportes (admin, supervisor)
                    └─▶ usuarios ─▶ usuario-form (solo admin)
```

## Principios de diseño
- Navegación lateral fija (colapsa en móvil), título y rol siempre visibles.
- Un patrón repetido: **lista con buscador + filtros → detalle → formulario**.
- Estados con color **y** texto (disponible/asignado/mantenimiento; stock bajo en rojo) – no depende solo del color.
- Formularios cortos, campos obligatorios marcados con `*`, `label` asociado a cada input, foco visible.
- Responsive: tablas con scroll horizontal, rejillas que se apilan.

## Flujos críticos (objetivo O3: ≤ 2 min)
1. **Registrar persona:** Personas → «+ Nueva persona» → 4 campos obligatorios → Guardar (≈ 3 clics, < 1 min).
2. **Consultar activo/persona:** buscador en la parte superior de la lista filtra al teclear (SKU, nombre, modelo compatible) → Ver (≈ 2 clics, < 30 s).
3. **Asignar herramienta:** Activos → Ver → seleccionar persona → Asignar.
